# Ansible Practice Repository (Terraform Infra)

This repository is created **purely for learning and practice purposes**.

I use this repo to practice **Ansible** on real cloud infrastructure, where the required resources are provisioned using **Terraform**. The main goal is to understand how **Terraform and Ansible work together** in real-world DevOps scenarios.


---

## 📌 Purpose

* Practice **Ansible concepts** on AWS EC2 instances
* Learn **Terraform + Ansible integration**
* Understand real-world **DevOps workflows**
* Gain hands-on experience instead of only theory

---

## 🛠 Tools & Technologies Used

* **Terraform** – Infrastructure provisioning
* **Ansible** – Configuration management
* **AWS** – Cloud provider
* **Linux** – Target operating system
* **Git** – Version control

---

## 📚 Learning Resources Used

The implementation and concepts in this repository are based on learning from:

* **Train With Shubham** (YouTube & learning content)
* **Official Documentation**

  * Terraform Docs
  * Ansible Docs
  * AWS Docs
* **Blogs, tutorials, and community articles**
* Hands-on practice and experimentation

---

## 🔄 Workflow Overview

1. Use **Terraform** to create AWS infrastructure
2. Use Terraform **outputs** (IP addresses, SSH access) for Ansible
3. Use **Ansible playbooks** to configure the provisioned instances
4. Destroy infrastructure using Terraform after practice

---

## 🔐 Notes

* Terraform state files are ignored
* SSH private keys are not committed
* AWS credentials are never stored in the repository

---

## 🎯 Disclaimer

This repository is created **only for learning, practice, and experimentation**.
Any configurations or setups here should not be directly used in production environments.
